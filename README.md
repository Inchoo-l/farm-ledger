# farm-ledger（田んぼ・畑の帳簿アプリ）

Farm ledger web app for rice fields and vegetable farms — runs in the browser, optional Google Drive sync.

田んぼ・畑の経費、売上、口座、作付、減価償却、区画マップを記録・集計する、ブラウザだけで動く帳簿アプリです。サーバーは持たず、データは利用者のブラウザと、利用者自身の Google ドライブにだけ置きます。家族での利用を想定しています。

## 主な機能

- 田んぼ／畑の切り替え、経費・売上・口座・作付・減価償却の記録と集計
- 区画マップ（作物ごとの色、マルチ・わらなどの被覆資材の表示、時系列表示）
- 経費の検索・絞り込み（全角半角・ひらがなカタカナの違いを吸収）
- 元に戻す／やり直す、JSON でのバックアップと復元
- 複数端末での共有（Google ドライブ同期）と、パスワードによる暗号化
- 自動バックアップ（任意。`backup-worker/`）

## 構成

ビルド不要の静的ファイル（素の JavaScript）です。

| 場所 | 内容 |
|---|---|
| `index.html`, `js/`, `css/`, `assets/` | アプリ本体 |
| `privacy.html` | プライバシーポリシー |
| `backup-worker/` | 自動バックアップ（Cloudflare Workers）。手順書・復元手順書あり |
| `デプロイ用フォルダを作る.ps1` | 公開用の `deploy/` フォルダを作る（`-Deploy` で公開まで） |

公開は Cloudflare Workers の静的アセットを使っています。

## データの置き場所

- 帳簿データ本体：ブラウザの localStorage（キー `agri-ledger-v1`）
- 共有ファイル：利用者の Google ドライブ直下の `sharedFolder.json`
- このリポジトリには、帳簿データも秘密情報も入っていません。

## Google ドライブ API の使い方（同期のしくみ）

端末どうしでデータを共有するため、Google Drive API を使っています。

- **認証**：ブラウザで Google のログイン部品（Google Identity Services）を使い、ログインのたびにアクセストークンを取ります。トークンはメモリ上だけに持ち、保存しません（約1時間で失効し、切れたら自動で取り直します）。
- **権限**：`https://www.googleapis.com/auth/drive.file` のみです。このアプリが作ったファイルだけが対象で、ドライブのほかのファイルは見えません。
- **共有ファイル**：ドライブ直下に `sharedFolder.json` を1つ作り、帳簿データ全体を JSON で保存します。無ければ新しく作ります。
- **同期**：変更があると自動で保存し、数秒おきに相手側の更新を確認して取り込みます。ほかの端末と同時に編集して内容が食い違ったときは、確認の画面を出します。
- **暗号化**：パスワードを設定すると、ファイルの中身を AES-256-GCM（鍵は PBKDF2 で導出）で暗号化してから保存します。パスワードは保存しません。忘れると復元できません。
- **クライアントID**：自分の Google Cloud で作った OAuth クライアントID を、アプリの画面から入力します。ID はブラウザにだけ保存されます。

### 自動バックアップ（任意）

`backup-worker/` は、毎日1回、共有ファイルを読んでドライブの「バックアップ」フォルダへ保存します（日曜はフル、ほかの日は増分）。Cloudflare Workers の Cron で動き、失敗は ntfy で通知します。設定は [設定手順書](backup-worker/設定手順書.md)、復元は [復元手順書](backup-worker/復元手順書.md) を見てください。

## 開発

```powershell
# 画面の確認：index.html をローカルサーバーで開く（file:// では Google ログインが使えません）
npx serve .

# 公開用フォルダの作成と公開
.\デプロイ用フォルダを作る.ps1 -Deploy
```
